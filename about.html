À propos de Shoply

Shoply est un projet de démonstration créé pour illustrer les compétences en développement frontend : HTML sémantique, JavaScript vanilla, Tailwind CSS, et intégration d'API REST. C'est un projet de portfolio — les produits, prix et avis proviennent d'une API publique de test (Fake Store API), et aucune transaction ni aucun achat réel n'a lieu sur ce site.

Contact

Ce site étant un projet de démonstration, ce formulaire n'envoie rien réellement. Dans une version en production, cette section contiendrait un formulaire de contact fonctionnel relié à un service d'envoi d'e-mails.

Pour toute question sur ce projet en particulier, vous pouvez me retrouver sur GitHub ou WhatsApp.

Questions fréquentes

Puis-je vraiment commander un produit ?

Non, le tunnel d'achat (panier, paiement, confirmation) est entièrement simulé à des fins de démonstration. Aucune transaction réelle n'est effectuée.

D'où viennent les produits affichés ?

Ils proviennent de la Fake Store API, une API publique gratuite destinée aux développeurs pour tester des applications e-commerce.

Mes favoris et mon panier sont-ils sauvegardés ?

Oui, localement dans votre navigateur (localStorage) — ils resteront présents si vous revenez plus tard, tant que vous ne videz pas les données de ce site dans votre navigateur.

Mentions légales

Shoply est un projet personnel réalisé à des fins d'apprentissage et de démonstration (portfolio). Il ne s'agit pas d'une entreprise réelle et ce site n'est pas destiné à la vente. Les catalogues, prix et avis produits affichés proviennent d'une API tierce de test et n'ont aucune valeur commerciale réelle.

Politique de confidentialité

Ce site ne collecte, ne transmet, ni ne stocke aucune donnée personnelle sur un serveur. Les seules données conservées (panier, favoris, historique de commandes simulées, préférence de thème) sont stockées localement dans le navigateur via `localStorage`, et restent uniquement sur votre appareil. Aucune information saisie dans le formulaire de commande n'est envoyée ni sauvegardée ailleurs que dans votre navigateur.
